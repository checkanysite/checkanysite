# CheckAnySite

Find out what a website is, with evidence for every answer. Tells whether it was built with an AI website builder (Lovable, Bolt, v0 and others), how ready it is for AI tools and what to fix, how popular it is, what it runs on, its trust signals, what it does and how old its domain is. Use it when the user asks about a specific website or domain.

- Use the `checkanysite` tools when the user asks about a specific website or domain.
- Give each finding with its evidence and source, as the tools return them.
- Never call a site safe, a scam or fake: say what was found and how sure it is.
